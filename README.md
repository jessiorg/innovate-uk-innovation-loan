# Innovate UK Innovation Loan — Working Repository

**EOI Deadline:** 9 October 2026, 11:00am (last window for 2026)
**Loan Amount:** £100k – £5M
**Interest:** 7.4% p.a. (3.7% payable during project, 3.7% deferred)
**Project Start:** From 1 December 2026

---

## Repository Structure

```
01-eligibility/          — Eligibility checklist, sector guide, common disqualifications
02-financial-mechanics/  — How the loan works: drawdowns, interest, repayment, debenture
03-due-diligence/        — What IUK checks, financial thresholds, covenants
04-eoi-draft/            — Draft EOI responses and project summary
05-financial-models/     — R/Python/Excel financial models: drawdown schedules, repayment scenarios
06-presentation/          — OpenDesign presentation materials
```

---

## The 2-Stage Process

```
EOI (no deadline, but 9 Oct 2026 is last window)
    ↓  (if approved)
Full Application (by invitation)
    ↓  (if approved)
Loan Documentation → Debenture → Quarterly Drawdowns
    ↓
Project Period (up to 5 years, interest payable at 3.7%)
    ↓
Repayment Period (up to 5 years, principal + deferred interest at 7.4%)
```
